# toggle-cursor-lock

A very simple fabric client-side mod, which allows you to lock and unlock the cursor.
Versions tested are 1.21.11 - 26.1.1, but version above/below may work regardless

## Downloading

You can download the mod by getting the latest built artifact from github actions, or at [this link](https://nightly.link/PSJahn/toggle-cursor-lock/workflows/build/master/Artifacts.zip)
